1. 交付与编辑入口

打开天气智农Figma原生文件。文件内有15个可编辑Frame、249个文本节点、60个组件实例和26条点击跳转；已建立颜色、布局变量与文本样式。页面结构和文字均可直接编辑，不是整页图片。文件节点与变量记录可定位交付内容。未导出本地.fig副本。

网页原型支持真正填写、校验、修改和保存。在文件方式打开时使用离线示例流程；由本地服务打开时调用真实接口，并将任务、监测和审计记录写入SQLite。Figma展示决策状态与跳转，网页验证字段输入与动态状态。

3. 表单、确认与恢复

复核页3项勾选为必填；复核人和意见不能空。退回填写缺口，不生成任务。任务期限晚于当前场景时间；编辑必须说明原因；取消和反馈至少4字。完成反馈必须核查沟渠与积水，现场记录时间不能在未来。输入错误显示在当前表单；请求失败保留输入，不显示“保存成功”。

重复创建使用幂等键，修改使用版本号。建议时效到期时需要重新查询。服务重启后重新登录、重新获取建议；已有任务从数据库读取。场景时间推进只用于查看逾期，不修改真实系统时钟；当前服务业务时钟固定为2026-07-18 12:00。

4. 组件与视觉规格

桌面Frame 1440×960，移动Frame390×844。基于原项目绿色风格建立Card、ButtonPrimary、ButtonSecondary等可复用组件，文本属性可修改；变量包含10组颜色基础值及语义别名、3组布局值，文本采用Noto Sans SC。相关容器采用Auto Layout。

对风险概览、复核、移动反馈做截图检查；15个Frame的内容高度均未超出容器。网页另外检查390px无横向溢出、弹层和完整操作。网页复核预览 · 移动概览。
